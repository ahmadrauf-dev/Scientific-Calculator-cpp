# Contributing

Thank you for your interest in contributing!

## How to Contribute

1. Fork the repository.
2. Create a new branch.

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes.
4. Test your code before submitting.
5. Commit your changes.

```bash
git commit -m "Add feature: matrix calculator"
```

6. Push your branch.

```bash
git push origin feature/your-feature-name
```

7. Open a Pull Request.

## Coding Guidelines

- Write clean and readable C++ code.
- Use meaningful variable and function names.
- Handle invalid input properly.
- Keep functions focused on a single task.
- Follow the existing project structure.

## AI usage policy
- AI usage is not allowed
- LLMs can be used for getting information how to write code but LLM or any other AI generated code will not be entertained.
- PR of AI generated Code will not be accepted

## Reporting Bugs

When opening an issue, include:
- Operating System
- Compiler and version
- Steps to reproduce
- Expected behavior
- Actual behavior

## Feature Requests

Before requesting a feature:
- Check existing issues.
- Clearly explain why the feature would be useful.

## Pull Request Checklist

- [ ] Code compiles successfully.
- [ ] No existing functionality is broken.
- [ ] New code follows the project's style.
- [ ] Documentation is updated if needed.

Thank you for helping improve this project!
